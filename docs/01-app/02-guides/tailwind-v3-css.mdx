Este guia mostra como instalar o [Tailwind CSS v3](https://v3.tailwindcss.com/) no seu app Next.js.

> **Bom saber:** Para a configuração mais recente do Tailwind 4, veja as [instruções de configuração do Tailwind CSS](/docs/app/getting-started/css#tailwind-css).

## Instalando o Tailwind v3 \{#installing-tailwind-v3}

Instale o Tailwind CSS e suas dependências peer e, em seguida, execute o comando `init` para gerar os arquivos `tailwind.config.js` e `postcss.config.js`:

```bash package="pnpm"
pnpm add -D tailwindcss@^3 postcss autoprefixer
npx tailwindcss init -p
```

```bash package="npm"
npm install -D tailwindcss@^3 postcss autoprefixer
npx tailwindcss init -p
```

```bash package="yarn"
yarn add -D tailwindcss@^3 postcss autoprefixer
npx tailwindcss init -p
```

```bash package="bun"
bun add -D tailwindcss@^3 postcss autoprefixer
bunx tailwindcss init -p
```

## Configurando o Tailwind v3 \{#configuring-tailwind-v3}

Configure os caminhos dos seus templates no arquivo `tailwind.config.js`:

<AppOnly>

```js filename="tailwind.config.js"
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    './app/**/*.{js,ts,jsx,tsx,mdx}',
    './pages/**/*.{js,ts,jsx,tsx,mdx}',
    './components/**/*.{js,ts,jsx,tsx,mdx}',
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

Adicione as diretivas do Tailwind ao seu arquivo CSS global:

```css filename="app/globals.css"
@tailwind base;
@tailwind components;
@tailwind utilities;
```

Importe o arquivo CSS no seu layout raiz:

```tsx filename="app/layout.tsx" switcher
import './globals.css'

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
import './globals.css'

export default function RootLayout({ children }) {
  return (
    <html lang="en">
      <body>{children}</body>
    </html>
  )
}
```

</AppOnly>

<PagesOnly>

```js filename="tailwind.config.js"
/** @type {import('tailwindcss').Config} */
module.exports = {
  content: [
    './pages/**/*.{js,ts,jsx,tsx,mdx}',
    './components/**/*.{js,ts,jsx,tsx,mdx}',
    './app/**/*.{js,ts,jsx,tsx,mdx}',
  ],
  theme: {
    extend: {},
  },
  plugins: [],
}
```

Adicione as diretivas do Tailwind ao seu arquivo CSS global:

```css filename="styles/globals.css"
@tailwind base;
@tailwind components;
@tailwind utilities;
```

Importe o arquivo CSS no seu arquivo `pages/_app.js`:

```jsx filename="pages/_app.js"
import '@/styles/globals.css'

export default function MyApp({ Component, pageProps }) {
  return <Component {...pageProps} />
}
```

</PagesOnly>

## Usando classes \{#using-classes}

Depois de instalar o Tailwind CSS e adicionar os estilos globais, você pode usar as classes utilitárias do Tailwind no seu app.

<AppOnly>

```tsx filename="app/page.tsx" switcher
export default function Page() {
  return <h1 className="text-3xl font-bold underline">Hello, Next.js!</h1>
}
```

```jsx filename="app/page.js" switcher
export default function Page() {
  return <h1 className="text-3xl font-bold underline">Hello, Next.js!</h1>
}
```

</AppOnly>

<PagesOnly>

```tsx filename="pages/index.tsx" switcher
export default function Page() {
  return <h1 className="text-3xl font-bold underline">Hello, Next.js!</h1>

```

```jsx filename="pages/index.js" switcher
export default function Page() {

```

</PagesOnly>

## Uso com Turbopack \{#usage-with-turbopack}

A partir do Next.js 13.1, o Tailwind CSS e o PostCSS têm suporte no [Turbopack](https://turbo.build/pack/docs/features/css#tailwind-css).
