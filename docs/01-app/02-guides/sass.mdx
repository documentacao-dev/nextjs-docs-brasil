O Next.js tem suporte integrado ao Sass depois que o pacote é instalado, usando as extensões `.scss` e `.sass`. Você pode usar Sass no nível do componente via CSS Modules, com a extensão `.module.scss` ou `.module.sass`.

Primeiro, instale o [`sass`](https://github.com/sass/sass):

```bash package="pnpm"
pnpm add -D sass
```

```bash package="npm"
npm install --save-dev sass
```

```bash package="yarn"
yarn add -D sass
```

```bash package="bun"
bun add -D sass
```

> **Bom saber**:
>
> O Sass oferece [duas sintaxes diferentes](https://sass-lang.com/documentation/syntax), cada uma com sua própria extensão.
> A extensão `.scss` exige que você use a [sintaxe SCSS](https://sass-lang.com/documentation/syntax#scss),
> enquanto a extensão `.sass` exige que você use a [sintaxe indentada ("Sass")](https://sass-lang.com/documentation/syntax#the-indented-syntax).
>
> Se você não tem certeza de qual escolher, comece com a extensão `.scss`, que é um superconjunto de CSS e não exige que você aprenda a sintaxe indentada ("Sass").

### Personalizando as opções do Sass \{#customizing-sass-options}

Se você quiser configurar as opções do Sass, use `sassOptions` no `next.config`.

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  sassOptions: {
    additionalData: `$var: red;`,
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */

const nextConfig = {
  sassOptions: {
    additionalData: `$var: red;`,
  },
}

module.exports = nextConfig
```

#### Implementação \{#implementation}

Você pode usar a propriedade `implementation` para especificar a implementação do Sass a ser usada. Por padrão, o Next.js usa o pacote [`sass`](https://www.npmjs.com/package/sass).

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const nextConfig: NextConfig = {
  sassOptions: {
    implementation: 'sass-embedded',
  },
}

export default nextConfig
```

```js filename="next.config.js" switcher
/** @type {import('next').NextConfig} */

const nextConfig = {
  sassOptions: {
    implementation: 'sass-embedded',
  },
}

module.exports = nextConfig
```

### Variáveis do Sass \{#sass-variables}

O Next.js aceita variáveis do Sass exportadas de arquivos CSS Module.

Por exemplo, usando a variável `primaryColor` exportada do Sass:

```scss filename="app/variables.module.scss"
$primary-color: #64ff00;

:export {
  primaryColor: $primary-color;
}
```

<AppOnly>

```jsx filename="app/page.js"
// maps to root `/` URL

import variables from './variables.module.scss'

export default function Page() {
  return <h1 style={{ color: variables.primaryColor }}>Hello, Next.js!</h1>
}
```

</AppOnly>

<PagesOnly>

```jsx filename="pages/_app.js"
import variables from '../styles/variables.module.scss'

export default function MyApp({ Component, pageProps }) {
  return (
    <Layout color={variables.primaryColor}>
      <Component {...pageProps} />
    </Layout>
  )
}
```

</PagesOnly>
