title: Como implementar JSON-LD no seu app Next.js
nav_title: JSON-LD
description: Aprenda a adicionar JSON-LD ao seu app Next.js para descrever seu conteúdo para mecanismos de busca e IA.
---

[JSON-LD](https://json-ld.org/) é um formato para dados estruturados que pode ser usado por mecanismos de busca e por IA para entender a estrutura da página além do conteúdo puro. Por exemplo, você pode usá-lo para descrever uma pessoa, um evento, uma organização, um filme, um livro, uma receita e muitos outros tipos de entidades.

Nossa recomendação atual para JSON-LD é renderizar os dados estruturados como uma tag `<script>` nos componentes `layout.js` ou `page.js`.

O trecho a seguir usa `JSON.stringify`, que não sanitiza strings maliciosas usadas em injeção de XSS. Para prevenir esse tipo de vulnerabilidade, você pode remover tags `HTML` do payload `JSON-LD`, por exemplo, substituindo o caractere `<` pelo seu equivalente unicode, `<`.

Revise a abordagem recomendada pela sua organização para sanitizar strings potencialmente perigosas, ou use alternativas mantidas pela comunidade para o `JSON.stringify`, como o [serialize-javascript](https://www.npmjs.com/package/serialize-javascript).

```tsx filename="app/products/[id]/page.tsx" switcher
export default async function Page({ params }) {
  const { id } = await params
  const product = await getProduct(id)

  const jsonLd = {
    '@context': 'https://schema.org',
    '@type': 'Product',
    name: product.name,
    image: product.image,
    description: product.description,
  }

  return (
    <section>
      {/* Add JSON-LD to your page */}
      <script
        type="application/ld+json"
        dangerouslySetInnerHTML={{
          __html: JSON.stringify(jsonLd).replace(/</g, '\\u003c'),
        }}
      />
      {/* ... */}
    </section>
  )
}
```

Você pode validar e testar seus dados estruturados com o [Rich Results Test](https://search.google.com/test/rich-results) do Google ou com o validador genérico [Schema Markup Validator](https://validator.schema.org/).

Você pode tipar seu JSON-LD com TypeScript usando pacotes da comunidade como o [`schema-dts`](https://www.npmjs.com/package/schema-dts):

```tsx
import { Product, WithContext } from 'schema-dts'

const jsonLd: WithContext<Product> = {
  '@context': 'https://schema.org',
  '@type': 'Product',
  name: 'Next.js Sticker',
  image: 'https://nextjs.org/imgs/sticker.png',
  description: 'Dynamic at the speed of static.',
}
```

> **Bom saber**: o componente `next/script` é otimizado para carregar e executar JavaScript. Como JSON-LD são dados estruturados, e não código executável, uma tag `<script>` nativa é a escolha certa aqui.
