Esta página mostra como usar vídeos em apps Next.js, explicando como armazenar e exibir arquivos de vídeo sem afetar a performance.

## Usando `<video>` e `<iframe>` \{#using-video-and-iframe}

Vídeos podem ser incorporados à página usando a tag HTML **`<video>`** para arquivos de vídeo diretos, e **`<iframe>`** para vídeos hospedados em plataformas externas.

### `<video>` \{#video}

A tag [`<video>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/video) do HTML pode incorporar conteúdo de vídeo hospedado por você ou servido diretamente, dando controle total sobre a reprodução e a aparência.

```jsx filename="app/ui/video.jsx"
export function Video() {
  return (
    <video
      width="320"
      height="240"
      poster="/path/to/poster.jpg"
      controls
      preload="none"
    >
      <source src="/path/to/video.mp4" type="video/mp4" />
      <track
        src="/path/to/captions.vtt"
        kind="subtitles"
        srcLang="en"
        label="English"
      />
      Your browser does not support the video tag.
    </video>
  )
}
```

### Atributos comuns da tag `<video>` \{#common-video-tag-attributes}

| Atributo      | Descrição                                                                                                        | Exemplo                              |
| ------------- | ---------------------------------------------------------------------------------------------------------------- | ------------------------------------ |
| `src`         | Especifica a origem do arquivo de vídeo.                                                                         | `<video src="/path/to/video.mp4" />` |
| `width`       | Define a largura do player de vídeo.                                                                             | `<video width="320" />`              |
| `height`      | Define a altura do player de vídeo.                                                                              | `<video height="240" />`             |
| `controls`    | Se presente, exibe o conjunto padrão de controles de reprodução.                                                 | `<video controls />`                 |
| `autoPlay`    | Inicia a reprodução automaticamente quando a página carrega. Observação: as políticas de reprodução automática variam entre navegadores. | `<video autoPlay />`                 |
| `loop`        | Repete a reprodução do vídeo em loop.                                                                            | `<video loop />`                     |
| `muted`       | Silencia o áudio por padrão. Costuma ser usado com `autoPlay`.                                                   | `<video muted />`                    |
| `poster`      | Uma imagem exibida na caixa do vídeo até que o primeiro quadro esteja disponível.                                | `<video poster="/poster.jpg" />`     |
| `preload`     | Especifica como o vídeo é pré-carregado. Valores: `none`, `metadata`, `auto`.                                    | `<video preload="none" />`           |
| `playsInline` | Permite a reprodução inline em dispositivos iOS, muitas vezes necessário para que a reprodução automática funcione no Safari do iOS. | `<video playsInline />`              |

> **Bom saber**: ao usar o atributo `autoPlay`, é importante incluir também o atributo `muted`, para garantir que o vídeo seja reproduzido automaticamente na maioria dos navegadores, e o atributo `playsInline`, para compatibilidade com dispositivos iOS.

Para uma lista completa dos atributos de vídeo, consulte a [documentação da MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/video#attributes).

### Boas práticas para vídeos \{#video-best-practices}

- **Dimensões:** defina `width` e `height`, ou um `aspect-ratio` no CSS, para que o navegador reserve a caixa antes de o arquivo carregar. Um vídeo sem dimensões colapsa e depois empurra o restante da página para baixo, o que conta contra o [Cumulative Layout Shift](https://web.dev/articles/cls).
- **Imagem de pôster:** use `poster` para preencher essa caixa reservada enquanto o vídeo carrega, principalmente com `preload="none"`, em que nenhum quadro é buscado até a reprodução começar.
- **Conteúdo de fallback:** ao usar a tag `<video>`, inclua conteúdo de fallback dentro da tag para navegadores que não oferecem suporte à reprodução de vídeo.
- **Legendas ou closed captions:** inclua legendas para usuários surdos ou com deficiência auditiva. Use a tag [`<track>`](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/track) com seus elementos `<video>` para especificar as fontes dos arquivos de legenda.
- **Controles acessíveis:** os controles de vídeo padrão do HTML5 são recomendados para navegação por teclado e compatibilidade com leitores de tela. Para necessidades mais avançadas, considere players de terceiros como [react-player](https://github.com/cookpete/react-player) ou [video.js](https://videojs.com/), que oferecem controles acessíveis e uma experiência consistente entre navegadores.

### `<iframe>` \{#iframe}

A tag `<iframe>` do HTML permite incorporar vídeos de plataformas externas, como YouTube ou Vimeo.

```jsx filename="app/page.jsx"
export default function Page() {
  return (
    <iframe src="https://www.youtube.com/embed/19g66ezsKAg" allowFullScreen />
  )
}
```

### Atributos comuns da tag `<iframe>` \{#common-iframe-tag-attributes}

| Atributo          | Descrição                                                                      | Exemplo                                |
| ----------------- | ------------------------------------------------------------------------------ | -------------------------------------- |
| `src`             | A URL da página a ser incorporada.                                             | `<iframe src="https://example.com" />` |
| `width`           | Define a largura do iframe.                                                    | `<iframe width="500" />`               |
| `height`          | Define a altura do iframe.                                                     | `<iframe height="300" />`              |
| `allowFullScreen` | Permite que o conteúdo do iframe seja exibido em tela cheia.                   | `<iframe allowFullScreen />`           |
| `sandbox`         | Ativa um conjunto extra de restrições sobre o conteúdo dentro do iframe.       | `<iframe sandbox />`                   |
| `loading`         | Otimiza o comportamento de carregamento (por exemplo, lazy loading).           | `<iframe loading="lazy" />`            |
| `style`           | Aplica CSS, como um `aspect-ratio`, para manter a caixa com um formato fixo.   | `<iframe style={{ border: 0 }} />`     |
| `title`           | Fornece um título para o iframe, para dar suporte à acessibilidade.            | `<iframe title="Description" />`       |

Um iframe sem dimensões colapsa até que o conteúdo carregue, assim como um vídeo. Defina `width` e `height` ou um `aspect-ratio`, principalmente com `loading="lazy"`, em que o embed pode terminar de carregar bem depois de a página ao redor já ter sido pintada.

Para uma lista completa dos atributos de iframe, consulte a [documentação da MDN](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/iframe#attributes).

### Escolhendo um método para incorporar vídeos \{#choosing-a-video-embedding-method}

Há duas formas de incorporar vídeos no seu app Next.js:

- **Arquivos de vídeo hospedados por você ou diretos:** incorpore vídeos hospedados por você com a tag `<video>` quando precisar de controle detalhado sobre as funcionalidades e a aparência do player. Essa integração dentro do Next.js permite personalizar e controlar seu conteúdo de vídeo.
- **Usando serviços de hospedagem de vídeo (YouTube, Vimeo etc.):** para serviços como YouTube ou Vimeo, você incorpora os players baseados em iframe deles com a tag `<iframe>`. Esse método limita parte do controle sobre o player, mas oferece facilidade de uso e os recursos fornecidos por essas plataformas.

Escolha o método de incorporação que combine com os requisitos do seu app e com a experiência de usuário que você quer oferecer.

### Incorporando vídeos hospedados externamente \{#embedding-externally-hosted-videos}

Para incorporar vídeos de plataformas externas, você pode usar o Next.js para buscar as informações do vídeo e o React Suspense para tratar o estado de fallback durante o carregamento.

**1. Crie um Server Component para incorporar o vídeo**

O primeiro passo é criar um [Server Component](/docs/app/getting-started/server-and-client-components) que gera o iframe apropriado para incorporar o vídeo. Esse componente vai buscar a URL de origem do vídeo e renderizar o iframe.

```jsx filename="app/ui/video-component.jsx"
export default async function VideoComponent() {
  const src = await getVideoSrc()

  return <iframe src={src} allowFullScreen />
}
```

**2. Use streaming no componente de vídeo com React Suspense**

Depois de criar o Server Component que incorpora o vídeo, o próximo passo é fazer [streaming](/docs/app/api-reference/file-conventions/loading) do componente usando o [React Suspense](https://react.dev/reference/react/Suspense).

```jsx filename="app/page.jsx"
import { Suspense } from 'react'
import VideoComponent from '../ui/VideoComponent.jsx'

export default function Page() {
  return (
    <section>
      <Suspense fallback={<p>Loading video...</p>}>
        <VideoComponent />
      </Suspense>
      {/* Other content of the page */}
    </section>
  )
}
```

> **Bom saber**: ao incorporar vídeos de plataformas externas, considere as seguintes boas práticas:
>
> - Garanta que os embeds de vídeo sejam responsivos. Use CSS para que o iframe ou o player de vídeo se adaptem a diferentes tamanhos de tela.
> - Implemente [estratégias para carregar vídeos](https://yoast.com/site-speed-tips-for-faster-video/) de acordo com as condições de rede, principalmente para usuários com planos de dados limitados.

Essa abordagem melhora a experiência do usuário, pois evita que a página fique bloqueada: o usuário pode interagir com a página enquanto o componente de vídeo é transmitido via streaming.

Para uma experiência de carregamento mais envolvente e informativa, considere usar um skeleton de carregamento como UI de fallback. Em vez de mostrar uma simples mensagem de carregamento, você pode exibir um skeleton que lembra o player de vídeo, assim:

```jsx filename="app/page.jsx"
import { Suspense } from 'react'
import VideoComponent from '../ui/VideoComponent.jsx'
import VideoSkeleton from '../ui/VideoSkeleton.jsx'

export default function Page() {
  return (
    <section>
      <Suspense fallback={<VideoSkeleton />}>
        <VideoComponent />
      </Suspense>
      {/* Other content of the page */}
    </section>
  )
}
```

## Vídeos hospedados por você \{#self-hosted-videos}

Hospedar vídeos por conta própria pode ser preferível por vários motivos:

- **Controle total e independência**: hospedar por conta própria dá gerenciamento direto sobre seu conteúdo de vídeo, da reprodução à aparência, garantindo propriedade e controle totais, livres das restrições de plataformas externas.
- **Personalização para necessidades específicas**: ideal para requisitos únicos, como vídeos de fundo dinâmicos, permite uma personalização sob medida para as necessidades de design e funcionalidade.
- **Considerações de performance e escalabilidade**: escolha soluções de armazenamento que sejam ao mesmo tempo de alta performance e escaláveis, para suportar o crescimento do tráfego e do tamanho do conteúdo de forma eficaz.
- **Custo e integração**: equilibre os custos de armazenamento e de banda com a necessidade de integração simples ao seu framework Next.js e ao restante do seu ecossistema tecnológico.

### Usando o Vercel Blob para hospedar vídeos \{#using-vercel-blob-for-video-hosting}

O [Vercel Blob](https://vercel.com/docs/vercel-blob?utm_source=next-site&utm_medium=docs&utm_campaign=next-website) oferece uma forma eficiente de hospedar vídeos, com uma solução de armazenamento em nuvem escalável que funciona bem com o Next.js. Veja como hospedar um vídeo usando o Vercel Blob:

**1. Enviando um vídeo para o Vercel Blob**

No seu dashboard da Vercel, acesse a aba "Storage" e selecione sua store do [Vercel Blob](https://vercel.com/docs/vercel-blob?utm_source=next-site&utm_medium=docs&utm_campaign=next-website). No canto superior direito da tabela de Blobs, encontre e clique no botão "Upload". Em seguida, escolha o arquivo de vídeo que deseja enviar. Depois que o upload terminar, o arquivo aparecerá na tabela de Blobs.

Como alternativa, você pode enviar seu vídeo usando uma server action. Para instruções detalhadas, consulte a documentação da Vercel sobre [uploads feitos no servidor](https://vercel.com/docs/vercel-blob/server-upload). A Vercel também oferece suporte a [uploads feitos no cliente](https://vercel.com/docs/vercel-blob/client-upload). Esse método pode ser preferível em alguns casos de uso.

**2. Exibindo o vídeo no Next.js**

Depois que o vídeo é enviado e armazenado, você pode exibi-lo no seu app Next.js. Veja um exemplo de como fazer isso usando a tag `<video>` e o React Suspense:

```jsx filename="app/page.jsx"
import { Suspense } from 'react'
import { list } from '@vercel/blob'

export default function Page() {
  return (
    <Suspense fallback={<p>Loading video...</p>}>
      <VideoComponent fileName="my-video.mp4" />
    </Suspense>
  )
}

async function VideoComponent({ fileName }) {
  const { blobs } = await list({
    prefix: fileName,
    limit: 1,
  })
  const { url } = blobs[0]

  return (
    <video controls preload="none" aria-label="Video player">
      <source src={url} type="video/mp4" />
      Your browser does not support the video tag.
    </video>
  )
}
```

Nessa abordagem, a página usa a URL do `@vercel/blob` do vídeo para exibi-lo com o `VideoComponent`. O React Suspense é usado para mostrar um fallback até que a URL do vídeo seja buscada e o vídeo esteja pronto para ser exibido.

### Adicionando legendas ao seu vídeo \{#adding-subtitles-to-your-video}

Se você tiver legendas para o seu vídeo, pode adicioná-las facilmente usando o elemento `<track>` dentro da tag `<video>`. Você pode buscar o arquivo de legenda no [Vercel Blob](https://vercel.com/docs/vercel-blob?utm_source=next-site&utm_medium=docs&utm_campaign=next-website) de forma semelhante ao arquivo de vídeo. Veja como atualizar o `<VideoComponent>` para incluir legendas.

```jsx filename="app/page.jsx"
async function VideoComponent({ fileName }) {
  const { blobs } = await list({
    prefix: fileName,
    limit: 2,
  })
  const { url } = blobs[0]
  const { url: captionsUrl } = blobs[1]

  return (
    <video controls preload="none" aria-label="Video player">
      <source src={url} type="video/mp4" />
      <track src={captionsUrl} kind="subtitles" srcLang="en" label="English" />
      Your browser does not support the video tag.
    </video>
  )
}
```

Seguindo essa abordagem, você pode hospedar vídeos por conta própria e integrá-los de forma eficaz aos seus apps Next.js.

## Recursos \{#resources}

Para continuar aprendendo sobre otimização de vídeo e boas práticas, consulte os recursos a seguir:

- **Entendendo formatos e codecs de vídeo**: escolha o formato e o codec certos para as suas necessidades, como MP4 para compatibilidade ou WebM para otimização na web. Para mais detalhes, veja o [guia da Mozilla sobre codecs de vídeo](https://developer.mozilla.org/en-US/docs/Web/Media/Formats/Video_codecs).
- **Compressão de vídeo**: use ferramentas como o FFmpeg para comprimir vídeos com eficiência, equilibrando qualidade e tamanho do arquivo. Saiba mais sobre técnicas de compressão no [site oficial do FFmpeg](https://www.ffmpeg.org/).
- **Ajuste de resolução e bitrate**: ajuste a [resolução e o bitrate](https://www.dacast.com/blog/bitrate-vs-resolution/#:~:text=The%20two%20measure%20different%20aspects,yield%20different%20qualities%20of%20video) de acordo com a plataforma de visualização, com configurações mais baixas para dispositivos móveis.
- **Content Delivery Networks (CDNs)**: use uma CDN para aumentar a velocidade de entrega de vídeos e lidar com um tráfego alto. Ao usar algumas soluções de armazenamento, como o Vercel Blob, a funcionalidade de CDN é tratada automaticamente para você. [Saiba mais](https://vercel.com/docs/cdn?utm_source=next-site&utm_medium=docs&utm_campaign=next-website) sobre CDNs e seus benefícios.

Conheça estas plataformas de streaming de vídeo para integrar vídeos aos seus projetos Next.js:
