O módulo [`next/font`](/docs/app/api-reference/components/font) otimiza automaticamente suas fontes e remove requisições de rede externas, para mais privacidade e desempenho.

Ele inclui **hospedagem própria integrada** para qualquer arquivo de fonte. Isso significa que você pode carregar fontes web de forma otimizada, sem deslocamento de layout.

<AppOnly>

Para começar a usar o `next/font`, importe-o de [`next/font/local`](#local-fonts) ou [`next/font/google`](#google-fonts), chame-o como uma função com as opções apropriadas e defina o `className` do elemento ao qual você quer aplicar a fonte. Por exemplo:

```tsx filename="app/layout.tsx" highlight={1,3-5,9} switcher
import { Geist } from 'next/font/google'

const geist = Geist({
  subsets: ['latin'],
})

export default function Layout({ children }: { children: React.ReactNode }) {
  return (
    <html lang="en" className={geist.className}>
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" highlight={1,3-5,9} switcher
import { Geist } from 'next/font/google'

const geist = Geist({
  subsets: ['latin'],
})

export default function Layout({ children }) {
  return (
    <html className={geist.className}>
      <body>{children}</body>
    </html>
  )
}
```

As fontes têm escopo no componente em que são usadas. Para aplicar uma fonte a todo o app, adicione-a ao [Layout raiz](/docs/app/api-reference/file-conventions/layout#root-layout).

</AppOnly>

## Google Fonts \{#google-fonts}

Você pode hospedar qualquer Google Font por conta própria, de forma automática. As fontes são incluídas como arquivos estáticos e servidas a partir do mesmo domínio do seu deploy, o que significa que o navegador não envia requisições ao Google quando o usuário visita seu site.

Para começar a usar uma Google Font, importe a fonte escolhida de `next/font/google`:

<AppOnly>

```tsx filename="app/layout.tsx" switcher
import { Geist } from 'next/font/google'

const geist = Geist({
  subsets: ['latin'],
})

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en" className={geist.className}>
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher

})

      <body>{children}</body>

```

</AppOnly>

## Fontes locais \{#local-fonts}

<AppOnly>

Para usar uma fonte local, importe a função `localFont` de `next/font/local` e especifique o [`src`](/docs/app/api-reference/components/font#src) do arquivo da fonte local. O caminho é relativo ao arquivo em que você chama `localFont`. Você pode guardar as fontes em qualquer lugar do projeto, inclusive na pasta [`public`](/docs/app/api-reference/file-conventions/public-folder) ou junto do código, dentro da pasta `app`. Por exemplo, para usar uma fonte armazenada em `app/fonts/`:

```tsx filename="app/layout.tsx" switcher
import localFont from 'next/font/local'

const myFont = localFont({
  src: './my-font.woff2',
})

export default function RootLayout({
  children,
}: {
  children: React.ReactNode
}) {
  return (
    <html lang="en" className={myFont.className}>
      <body>{children}</body>
    </html>
  )
}
```

```jsx filename="app/layout.js" switcher
import localFont from 'next/font/local'

const myFont = localFont({
  src: './my-font.woff2',
})

export default function RootLayout({ children }) {
  return (
    <html lang="en" className={myFont.className}>
      <body>{children}</body>
    </html>
  )
}
```

</AppOnly>

<PagesOnly>

Para usar uma fonte local, importe sua fonte de `next/font/local` e especifique o [`src`](/docs/pages/api-reference/components/font#src) do arquivo da fonte local. Você pode guardar as fontes na pasta [`public`](/docs/pages/api-reference/file-conventions/public-folder) ou dentro da pasta `pages`. Por exemplo:

```tsx filename="pages/_app.tsx" switcher
import localFont from 'next/font/local'
import type { AppProps } from 'next/app'

const myFont = localFont({
  src: './my-font.woff2',
})

export default function MyApp({ Component, pageProps }: AppProps) {
  return (

      <Component {...pageProps} />
    </main>

```


</PagesOnly>

Se você quiser usar vários arquivos para uma única família de fontes, `src` pode ser um array:

```js
const roboto = localFont({
  src: [
    {
      path: './Roboto-Regular.woff2',
      weight: '400',
      style: 'normal',
    },
    {
      path: './Roboto-Italic.woff2',
      weight: '400',
      style: 'italic',
    },
    {
      path: './Roboto-Bold.woff2',
      weight: '700',
      style: 'normal',
    },
    {
      path: './Roboto-BoldItalic.woff2',
      weight: '700',
      style: 'italic',
    },
  ],
})
```
