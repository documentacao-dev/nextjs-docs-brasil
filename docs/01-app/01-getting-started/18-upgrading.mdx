## Versão mais recente \{#latest-version}

Para atualizar para a versão mais recente do Next.js, use o comando `upgrade`:

```bash package="pnpm"
pnpm next upgrade
```

```bash package="npm"
npx next upgrade
```

```bash package="yarn"
yarn next upgrade
```

```bash package="bun"
bunx next upgrade
```

Versões anteriores ao Next.js 16.1.0 não têm suporte ao comando `upgrade` e precisam usar um pacote separado:

```bash filename="Terminal"
npx @next/codemod@canary upgrade latest
```

Para que um agente de código faça e verifique a atualização, execute:

```bash filename="Terminal"
npx next@canary upgrade --agent=latest
```

Veja [Atualizar com um agente de código](/docs/app/guides/upgrading/agent-upgrade) para outras políticas e lembretes de atualização.

Se você preferir atualizar manualmente, instale a versão mais recente do Next.js e do React:

```bash package="pnpm"
pnpm i next@latest react@latest react-dom@latest eslint-config-next@latest
```

```bash package="npm"
npm i next@latest react@latest react-dom@latest eslint-config-next@latest
```

```bash package="yarn"
yarn add next@latest react@latest react-dom@latest eslint-config-next@latest
```

```bash package="bun"
bun add next@latest react@latest react-dom@latest eslint-config-next@latest
```

## Versão canary \{#canary-version}

Para atualizar para o canary mais recente, confirme que você está na versão mais recente do Next.js e que tudo está funcionando como esperado. Depois, execute o comando a seguir:

```bash package="pnpm"
pnpm add next@canary
```

```bash package="npm"
npm i next@canary
```

```bash package="yarn"
yarn add next@canary
```

```bash package="bun"
bun add next@canary
```

### Recursos disponíveis no canary \{#features-available-in-canary}

No momento, os recursos a seguir estão disponíveis no canary:

**Autenticação**:

- [`forbidden`](/docs/app/api-reference/functions/forbidden)
- [`unauthorized`](/docs/app/api-reference/functions/unauthorized)
- [`forbidden.js`](/docs/app/api-reference/file-conventions/forbidden)
- [`unauthorized.js`](/docs/app/api-reference/file-conventions/unauthorized)
- [`authInterrupts`](/docs/app/api-reference/config/next-config-js/authInterrupts)
