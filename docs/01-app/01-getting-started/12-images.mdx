O componente [`<Image>`](/docs/app/api-reference/components/image) do Next.js estende o elemento HTML `<img>` para oferecer:

- **Otimização de tamanho:** Serve automaticamente imagens com o tamanho certo para cada dispositivo, usando formatos modernos como WebP.
- **Estabilidade visual:** Evita automaticamente o [layout shift](https://web.dev/articles/cls) enquanto as imagens carregam.
- **Carregamento de página mais rápido:** Carrega imagens somente quando entram na viewport, usando o lazy loading nativo do navegador, com placeholders opcionais de blur-up.
- **Flexibilidade de assets:** Redimensiona imagens sob demanda, inclusive imagens armazenadas em servidores remotos.

Para começar a usar `<Image>`, importe-o de `next/image` e renderize-o dentro de um componente.

```tsx filename="app/page.tsx" switcher
import Image from 'next/image'

export default function Page() {
  return <Image src="" alt="" />
}
```

```jsx filename="app/page.js" switcher
import Image from 'next/image'

export default function Page() {
  return <Image src="" alt="" />
}
```

A propriedade `src` pode ser uma imagem [local](#local-images) ou [remota](#remote-images).

> **🎥 Assista:** Saiba mais sobre como usar `next/image` → [YouTube (9 minutos)](https://youtu.be/IU_qq_c_lKA).

## Imagens locais \{#local-images}

Você pode armazenar arquivos estáticos, como imagens e fontes, em uma pasta chamada [`public`](/docs/app/api-reference/file-conventions/public-folder) na raiz do projeto. Os arquivos dentro de `public` podem ser referenciados no código a partir da URL base (`/`).

  srcLight="/docs/light/public-folder.png"
  srcDark="/docs/dark/public-folder.png"
  width="1600"

/>

```tsx filename="app/page.tsx" switcher
import Image from 'next/image'

export default function Page() {
  return (
    <Image
      src="/profile.png"
      alt="Picture of the author"
      width={500}
      height={500}
    />
  )
}
```

```jsx filename="app/page.js" switcher
import Image from 'next/image'

export default function Page() {
  return (
    <Image
      src="/profile.png"
      alt="Picture of the author"
      width={500}
      height={500}
    />
  )
}
```

Se a imagem for importada estaticamente, o Next.js determina automaticamente a [`width`](/docs/app/api-reference/components/image#width-and-height) e a [`height`](/docs/app/api-reference/components/image#width-and-height) intrínsecas. Esses valores são usados para calcular a proporção da imagem e evitar o [Cumulative Layout Shift](https://web.dev/articles/cls) enquanto ela carrega.

```tsx filename="app/page.tsx" switcher
import Image from 'next/image'
import ProfileImage from './profile.png'

export default function Page() {
  return (
    <Image
      src={ProfileImage}
      alt="Picture of the author"
      // width={500} automatically provided
      // height={500} automatically provided
      // blurDataURL="data:..." automatically provided
      // placeholder="blur" // Optional blur-up while loading
    />
  )
}
```

```jsx filename="app/page.js" switcher
import Image from 'next/image'
import ProfileImage from './profile.png'

export default function Page() {
  return (
    <Image
      src={ProfileImage}
      alt="Picture of the author"
      // width={500} automatically provided
      // height={500} automatically provided
      // blurDataURL="data:..." automatically provided
      // placeholder="blur" // Optional blur-up while loading
    />
  )
}
```

### Imagens sem importação estática \{#images-without-static-imports}

Se você não puder usar um `import` estático para suas imagens, pode usar um `import()` dinâmico em um Server Component para continuar obtendo `width`, `height` e `blurDataURL` automaticamente:

```tsx filename="app/blog/[slug]/page.tsx" switcher
import Image from 'next/image'

async function PostImage({
  imageFilename,
  alt,
}: {
  imageFilename: string
  alt: string
}) {
  const { default: image } = await import(
    `../content/blog/images/${imageFilename}`
  )
  // image contains width, height, and blurDataURL
  return <Image src={image} alt={alt} />
}
```

```jsx filename="app/blog/[slug]/page.js" switcher
import Image from 'next/image'

async function PostImage({ imageFilename, alt }) {
  const { default: image } = await import(
    `../content/blog/images/${imageFilename}`
  )
  // image contains width, height, and blurDataURL
  return <Image src={image} alt={alt} />
}
```

Se você tiver um [alias de caminho](https://www.typescriptlang.org/tsconfig/#paths) configurado (por exemplo `@/`), pode usá-lo no lugar de um caminho relativo:

```tsx
const { default: image } = await import(
  `@/content/blog/images/${imageFilename}`
)
```

O caminho deve incluir um prefixo estático (como `../content/blog/images/`). Seja o mais específico possível, pois **todos** os arquivos que correspondem a esse prefixo são empacotados. Somente os arquivos do diretório especificado são incluídos, então uma entrada externa não consegue sair dele.

## Imagens remotas \{#remote-images}

Para usar uma imagem remota, forneça uma string de URL na propriedade `src`.

```tsx filename="app/page.tsx" switcher
import Image from 'next/image'

export default function Page() {
  return (
    <Image
      src="https://s3.amazonaws.com/my-bucket/profile.png"
      alt="Picture of the author"
      width={500}
      height={500}
    />
  )
}
```

```jsx filename="app/page.js" switcher
import Image from 'next/image'

export default function Page() {
  return (
    <Image
      src="https://s3.amazonaws.com/my-bucket/profile.png"
      alt="Picture of the author"
      width={500}
      height={500}
    />
  )
}
```

Como o Next.js não tem acesso a arquivos remotos durante o processo de build, você precisa fornecer manualmente as props [`width`](/docs/app/api-reference/components/image#width-and-height), [`height`](/docs/app/api-reference/components/image#width-and-height) e, opcionalmente, [`blurDataURL`](/docs/app/api-reference/components/image#blurdataurl). `width` e `height` são usados para inferir a proporção correta da imagem e evitar o layout shift causado pelo carregamento. Como alternativa, você pode usar a [propriedade `fill`](/docs/app/api-reference/components/image#fill) para fazer a imagem preencher o tamanho do elemento pai.

Para permitir com segurança imagens de servidores remotos, você precisa definir uma lista de padrões de URL aceitos em [`next.config.js`](/docs/app/api-reference/config/next-config-js). Seja o mais específico possível para evitar uso malicioso. Por exemplo, a configuração a seguir permite somente imagens de um bucket específico do AWS S3:

```ts filename="next.config.ts" switcher
import type { NextConfig } from 'next'

const config: NextConfig = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 's3.amazonaws.com',
        port: '',
        pathname: '/my-bucket/**',
        search: '',
      },
    ],
  },
}

export default config
```

```js filename="next.config.js" switcher
module.exports = {
  images: {
    remotePatterns: [
      {
        protocol: 'https',
        hostname: 's3.amazonaws.com',
        port: '',
        pathname: '/my-bucket/**',
        search: '',
      },
    ],
  },
}
```
