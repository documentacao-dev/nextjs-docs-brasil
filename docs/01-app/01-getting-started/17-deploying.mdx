O Next.js pode passar por deploy como servidor Node.js, contêiner Docker, exportação estática ou ser adaptado para rodar em diferentes plataformas.

| Opção de deploy                  | Suporte a recursos                                                    |
| -------------------------------- | --------------------------------------------------------------------- |
| [Servidor Node.js](#nodejs-server) | Todos                                                               |
| [Contêiner Docker](#docker)      | Todos                                                                 |
| [Exportação estática](#static-export) | Limitado                                                         |
| [Adaptadores](#adapters)         | Varia ([adaptadores verificados](#verified-adapters) rodam a suíte de testes) |

## Servidor Node.js \{#nodejs-server}

Você pode fazer deploy do Next.js em qualquer provedor que aceite Node.js. Garanta que seu `package.json` tenha os scripts `"build"` e `"start"`:

```json filename="package.json"
{
  "scripts": {
    "dev": "next dev",
    "build": "next build",
    "start": "next start"
  }
}
```

Depois, rode `npm run build` para [fazer o build do app](/docs/app/guides/building) e `npm run start` para iniciar o servidor Node.js. Esse servidor oferece suporte a todos os recursos do Next.js. Se precisar, também é possível migrar para um [servidor customizado](/docs/app/guides/custom-server).

Deploys em Node.js oferecem suporte a todos os recursos do Next.js. Saiba como [configurá-los](/docs/app/guides/self-hosting) para sua infraestrutura.

## Docker \{#docker}

Você pode fazer deploy do Next.js em qualquer provedor que aceite contêineres [Docker](https://www.docker.com/). Isso inclui orquestradores de contêineres como o Kubernetes ou um provedor de nuvem que rode Docker. Para boas práticas de containerização do seu app, consulte os guias oficiais do Docker sobre [Next.js](https://docs.docker.com/guides/nextjs) e [React.js](https://docs.docker.com/guides/reactjs).

Deploys com Docker oferecem suporte a todos os recursos do Next.js. Saiba como [configurá-los](/docs/app/guides/self-hosting) para sua infraestrutura.

> **Nota para desenvolvimento:** embora o Docker seja excelente para deploys em produção, considere usar o desenvolvimento local (`npm run dev`) em vez do Docker durante o desenvolvimento no Mac e no Windows, para ter um desempenho melhor. [Saiba mais sobre como otimizar o desenvolvimento local](/docs/app/guides/local-development).

### Modelos \{#templates-1}

Os exemplos a seguir demonstram boas práticas para colocar apps Next.js em contêineres:

- [Saída standalone com Docker](https://github.com/vercel/next.js/tree/canary/examples/with-docker) - Faça o deploy de um app Next.js usando `output: "standalone"` para gerar uma imagem Docker mínima e pronta para produção, com apenas os arquivos de runtime e as dependências necessárias.
- [Saída de exportação com Docker](https://github.com/vercel/next.js/tree/canary/examples/with-docker-export-output) - Faça o deploy de um app Next.js totalmente estático usando `output: "export"` para gerar arquivos HTML otimizados, que podem ser servidos a partir de um contêiner leve ou de qualquer hospedagem estática.
- [Múltiplos ambientes com Docker](https://github.com/vercel/next.js/tree/canary/examples/with-docker-multi-env) - Gerencie configurações separadas do Docker para os ambientes de desenvolvimento, homologação e produção, com variáveis de ambiente diferentes.

Além disso, provedores de hospedagem oferecem guias para fazer o deploy do Next.js:

## Exportação estática \{#static-export}

O Next.js permite começar como um site estático ou como [App de página única (SPA)](/docs/app/guides/single-page-applications) e, depois, opcionalmente, evoluir para recursos que exigem um servidor.

Como o Next.js oferece suporte a [exportações estáticas](/docs/app/guides/static-exports), ele pode receber deploy e ser hospedado em qualquer servidor web capaz de servir arquivos estáticos de HTML, CSS e JS. Isso inclui ferramentas como AWS S3, Nginx ou Apache.

Rodar como [exportação estática](/docs/app/guides/static-exports) **não** oferece suporte aos recursos do Next.js que exigem um servidor. [Saiba mais](/docs/app/guides/static-exports#unsupported-features).

## Adaptadores \{#adapters}

O Next.js pode ser adaptado para rodar em diferentes plataformas, de modo a aproveitar os recursos de infraestrutura de cada uma. A [API de Adaptadores de Deploy](/docs/app/api-reference/config/next-config-js/adapterPath) permite que as plataformas personalizem a forma como os apps Next.js passam por build e deploy.

### Adaptadores verificados \{#verified-adapters}

Adaptadores verificados são de código aberto, rodam a [suíte completa de testes de compatibilidade do Next.js](/docs/app/api-reference/adapters/testing-adapters) e são hospedados na [organização do Next.js no GitHub](https://github.com/nextjs). A equipe do Next.js coordena os testes com essas plataformas antes de grandes lançamentos. Os resultados públicos de testes de cada adaptador estão chegando em breve. [Saiba mais sobre adaptadores verificados](/docs/app/guides/deploying-to-platforms#verified-adapters).

- [Vercel](https://vercel.com/docs/frameworks/full-stack/nextjs)
- [Bun](https://bun.com/docs/guides/ecosystem/nextjs)

Cloudflare e Netlify estão trabalhando em adaptadores verificados baseados na API de Adaptadores. Enquanto isso, elas oferecem as próprias integrações com o Next.js (veja abaixo).

### Outras plataformas \{#other-platforms}

As plataformas a seguir oferecem as próprias integrações com o Next.js. Elas não usam a [API de Adaptadores](/docs/app/api-reference/config/next-config-js/adapterPath) pública como base e não são verificadas pela equipe do Next.js, por isso o suporte a recursos e a compatibilidade podem variar. Consulte a documentação de cada provedor para mais detalhes:

- [Appwrite Sites](https://appwrite.io/docs/products/sites/quick-start/nextjs)
- [AWS Amplify Hosting](https://docs.amplify.aws/nextjs/start/quickstart/nextjs-app-router-client-components)
- [Cloudflare](https://developers.cloudflare.com/workers/frameworks/framework-guides/nextjs)
- [Deno Deploy](https://docs.deno.com/examples/next_tutorial)
- [Firebase App Hosting](https://firebase.google.com/docs/app-hosting/get-started)
- [Netlify](https://docs.netlify.com/frameworks/next-js/overview/#next-js-support-on-netlify)

Para detalhes sobre quais recursos do Next.js exigem capacidades específicas de cada plataforma, veja [Deploy em plataformas](/docs/app/guides/deploying-to-platforms).
