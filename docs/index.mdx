Bem-vindo à documentação do Next.js!

## O que é o Next.js? \{#what-is-nextjs}

O Next.js é um framework React para criar apps web full-stack. Você usa componentes React para construir interfaces, e o Next.js para recursos adicionais e otimizações.

Ele também configura automaticamente ferramentas de baixo nível, como bundlers e compiladores. Assim, você pode focar em construir seu produto e entregá-lo rapidamente.

Seja você um desenvolvedor individual ou parte de um time maior, o Next.js pode ajudar a criar apps React interativos, dinâmicos e rápidos.

## App Router e Pages Router \{#app-router-and-pages-router}

O Next.js tem dois roteadores diferentes:

- **App Router**: O roteador mais novo, que aceita recursos recentes do React, como Server Components.
- **Pages Router**: O roteador original, ainda com suporte e em constante melhoria.

No topo da barra lateral, você vai encontrar um menu suspenso que permite alternar entre a documentação do [App Router](/docs/app) e do [Pages Router](/docs/pages).

### Como cada roteador lida com a versão do React \{#react-version-handling}

O App Router e o Pages Router tratam as versões do React de formas diferentes:

- **App Router**: Usa de forma integrada as [versões canary do React](https://react.dev/blog/2023/05/03/react-canaries), que incluem todas as mudanças estáveis do React 19, além de recursos mais novos que estão sendo validados nos frameworks antes de um novo lançamento do React.

- **Pages Router**: Usa a versão do React instalada no `package.json` do seu projeto.

Essa abordagem garante que os novos recursos do React funcionem de forma confiável no App Router, mantendo a retrocompatibilidade com os apps existentes que usam o Pages Router.

## Conhecimentos prévios \{#pre-requisite-knowledge}

A documentação pressupõe alguma familiaridade com desenvolvimento web. Antes de começar, convém que você se sinta à vontade com:

- HTML
- CSS
- JavaScript
- React

Se você é novo no React ou precisa de uma revisão, recomendamos começar pelo nosso [curso React Foundations](/learn/react-foundations) e pelo [curso Next.js Foundations](/learn/dashboard-app), em que você constrói um app enquanto aprende.

## Acessibilidade \{#accessibility}
